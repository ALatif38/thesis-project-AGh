## Project Overview

The Multitrack Podcast Video Editor is a proposed desktop application designed to simplify the editing of podcast recordings captured using multiple audio and video sources.

The application aims to provide an intuitive workflow for organising recordings, synchronising media tracks, editing conversations, mixing audio, selecting video tracks, and exporting the final composition.

## Project Objectives

The main objectives are:

- Develop a desktop application for podcast editing.
- Support importing multiple audio and video recordings.
- Organise recordings by participant.
- Synchronise recordings using a shared timeline.
- Remove unwanted sections of conversations.
- Select visible video tracks.
- Mix multiple audio tracks.
- Preview edited compositions.
- Export the final video or audio locally.
- Save and reopen editing projects.

# Project Application

## Project

**2026-LG-01 — Multitrack Podcast Video Editor**

**Supervisor:** Gergely Laborci

## Motivation

I would like to work on this project because I am interested in practical software development and building applications that combine modern desktop technologies with audio and video processing. This project particularly interests me because it addresses a real-world challenge and involves developing a complete software solution, from user interaction and data management to media preview and rendering.

I am especially interested in designing a multitrack editing workflow that allows users to synchronise separate audio and video recordings, organise tracks by participant, and manage editing decisions through a shared timeline. I would also like to explore how JavaScript or TypeScript, desktop application frameworks, and media-processing technologies can be combined to create an efficient and accessible editing experience.

Through this project, I aim to strengthen my knowledge of software architecture, multimedia processing, persistent data management, and user-interface development while creating a well-structured, maintainable, and reproducible application.

## Project Objectives

The main objective is to develop a desktop application that enables users to:

- Create and manage podcast editing projects.
- Import audio and video recordings from multiple sources.
- Assign recordings to individual participants.
- Synchronise tracks using a common timeline.
- Remove unwanted sections of recorded conversations.
- Select visible video tracks and audible audio tracks.
- Mix multiple audio tracks with adjustable gain.
- Configure video pan and zoom transformations.
- Preview the edited composition.
- Export the final video or voice-only audio locally.
- Save and reopen projects without losing editing decisions.

## Expected Outcome

The expected outcome is a functional desktop application that simplifies the preparation of multitrack podcast recordings and produces a synchronised, edited video or voice-only composition.

The project will focus on podcast content editing rather than general-purpose video post-production.
